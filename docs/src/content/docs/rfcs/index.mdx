This section collects the **Requests for Comments (RFCs)** that define the design of Platform Manager.

Each RFC proposes a piece of the system's domain model, semantics, or APIs. They're written as a series: rule and caveat numbers are shared across documents, so a rule keeps the same number regardless of which RFC it's defined in, and later RFCs freely reference earlier ones.

Browse the RFCs in the sidebar, starting with [RFC-001](rfcs/rfc-001-domain-model-and-ownership).
